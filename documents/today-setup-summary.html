ServiceNow Artifact Exporter — Setup Summary

This document summarizes what was set up today, how the workflow was built, and which dependencies matter for the project.

1. What was created

  • A JavaScript-based CLI tool for exporting ServiceNow artifacts as XML.
  • A local configuration flow using config.json with profile-based instance settings.
  • An output folder for generated XML and HTML analysis documents.
  • A small test suite and a documentation README.

2. What was learned today

  • ServiceNow personal developer instances can be accessed through the REST API using basic authentication.
  • The exporter can query a table such as sys_script_include and produce XML for review.
  • Authentication issues may appear as HTTP 401 errors and should be checked carefully.
  • Configuration should be kept local and private, and ignored by source control.
  • Exported artifacts can be analyzed offline for code review, gap analysis, and instance comparison.

3. How the setup was done

  1. Created a Node.js project structure with package.json.
  2. Implemented a CLI entry point in src/index.js.
  3. Added config loading from config.json and support for named profiles.
  4. Used axios to call the ServiceNow REST API and export records as XML.
  5. Wrote XML files into an out folder and analysis HTML into a documents folder.
  6. Verified the connection through REST requests and corrected the setup when needed.

4. Main project files

File Purpose
src/index.js Main exporter CLI logic.
package.json Project metadata and dependencies.
config.json Local instance credentials and profile settings.
config.example.json Safe example template for the configuration.
README.md Usage instructions and project overview.
documents/ Folder for HTML analysis reports.

5. Dependencies installed

Dependency Why it matters
axios Used to send HTTP requests to the ServiceNow REST API and handle authentication and response parsing.

Why Node.js and npm matter: Node.js is the runtime that executes the JavaScript CLI, and npm is the package manager used to install dependencies like axios.

6. How to run the project

cd c:\Users\91756\OneDrive\Desktop\myPortfolio
npm install
node src/index.js --config ./config.json --profile dev --artifact-types sys_script_include --names global

7. Why this project is useful

  • It helps export ServiceNow artifacts locally for code review.
  • It supports offline analysis and comparison between instances.
  • It creates a reusable workflow for collecting service logic and configuration as XML.
  • It can be extended later for bulk export, richer metadata, and multi-instance support.

8. Final takeaway

Today’s work established a practical ServiceNow artifact export workflow from a personal developer instance using a lightweight Node.js CLI. The core learning was how to connect to the REST API, authenticate safely, export records as XML, and organize the results for analysis.
